# Solicitudes de cotización: animaciones de ejercicios

Adjunto para ambos: `ejercicios.csv` (116 ejercicios; se regenera con `npm run exercise-list`).
Los mensajes van en inglés porque ambos proveedores trabajan en inglés.

---

## 1. Gymvisual

- **Dónde:** formulario en https://gymvisual.com/contact-gymvisual
- **Subject Heading:** Customer service
- **Email address:** tu correo
- **Attach File:** `ejercicios.csv`
- **Message:**

```
Hello,

I'm building a mobile training app (iOS and Android, Spanish-speaking market) focused on home and outdoor workouts with kettlebells, bodyweight, resistance bands and a few dumbbell / pull-up bar exercises. It's currently an MVP before launch.

I'd like a quote for animated exercise demonstrations to show inside the app, for the 116 exercises in the attached list (the "id" column is in English; categories: warm-up, prehab/rehab, strength and stretching).

Could you please tell me:
1. Which of these exercises you already have as animated GIFs and/or videos, and which are missing.
2. The price for the whole set (or the closest pack), and per item.
3. Whether you can create the missing ones on request, and the price and turnaround.
4. The license terms for use inside a commercial mobile app distributed on the App Store and Google Play (perpetual or annual, number of users/downloads, any attribution required).
5. Available formats and resolutions (MP4 / GIF / WebM, background color or transparent), and whether both male and female models are available.

Thank you,
Rodrigo Pérez
```

## 2. WorkoutLabs

- **Dónde:** botón "Submit an inquiry" en https://workoutlabs.com/exercise-illustrations-licensing/ (formulario de Google). Si el formulario no permite adjuntar, pega la lista o envía el CSV cuando respondan.
- **Precios de referencia que publican:** desde US$15 por ilustración (anual) o US$25 (perpetua), con descuento sobre 15 imágenes; biblioteca completa (679) desde US$1.200/año o US$3.500+ perpetua. Las animaciones son un extra.
- **Mensaje:**

```
Hello,

I'm building a mobile training app (iOS and Android, Spanish-speaking market) focused on home and outdoor workouts with kettlebells, bodyweight, resistance bands and a few dumbbell / pull-up bar exercises. It's currently an MVP before launch.

I'd like a quote for animated exercise illustrations (MP4 or GIF, ideally also a static PNG/SVG) for a list of 116 exercises (warm-up, prehab/rehab, strength and stretching) that I can send as a CSV.

Could you please tell me:
1. Which of these exercises are in your library with animation, and which are missing.
2. Price for this selection, perpetual vs. annual license, for in-app use in a commercial mobile app.
3. Whether you can create the missing ones (especially kettlebell exercises), with price and turnaround.
4. Available character options (male/female, color style) and whether a dark-background version is possible.

Thank you,
Rodrigo Pérez
```
